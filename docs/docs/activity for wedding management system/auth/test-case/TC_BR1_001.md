### Description

This test case verifies the display of the LoginWindow screen when the user launches the Wedding Management System (WMS) application. It ensures that the login screen displays correctly according to the design with all required UI components.

### Detailed Steps

| Step | Steps to Perform                                           | Step Expected Result                                                                        |
| ---- | ---------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| 1    | Launch WMS application from desktop shortcut or Start menu | Application starts loading, displays splash screen (if any)                                 |
| 2    | Wait for the application to finish loading                 | Loading process completes within 5 seconds                                                  |
| 3    | Observe the LoginWindow screen display                     | LoginWindow screen displays all components: Logo, UsernameTextBox, PasswordBox, LoginButton |

### Overall Expected Result

LoginWindow displays correctly according to design with all UI components:

- WMS Logo
- Username input field (UsernameTextBox) - editable
- Password input field (PasswordBox) - input is masked
- Login button (LoginButton) - clickable

### Pass/Fail Criteria

| Criteria            | Pass                            | Fail                                 |
| ------------------- | ------------------------------- | ------------------------------------ |
| LoginWindow display | ✓ Displays correctly            | ✗ Does not display or error occurs   |
| UsernameTextBox     | ✓ Visible and editable          | ✗ Not visible or disabled            |
| PasswordBox         | ✓ Visible and masks input       | ✗ Not visible or does not mask input |
| LoginButton         | ✓ Visible and clickable         | ✗ Not visible or disabled            |
| Layout              | ✓ Matches design specifications | ✗ Layout misalignment                |
