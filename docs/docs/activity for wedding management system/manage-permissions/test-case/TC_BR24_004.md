### Filter Logic

```csharp
// Current user's group is excluded to prevent self-modification
string currentGroupId = SessionService.CurrentUser.GroupId;
GroupList = db.UserGroups
    .Where(g => g.GroupId != currentGroupId)
    .ToList();
```
