### Method Flow

```csharp
private void UpdatePermissionStates()
{
    var groupPermissions = db.GroupPermissions
        .Where(gp => gp.GroupId == SelectedItem.GroupId)
        .Select(gp => gp.PermissionId)
        .ToList();

    foreach (var permission in PermissionStates.Keys)
    {
        PermissionStates[permission].IsChecked =
            groupPermissions.Contains(permission);
    }
}
```
