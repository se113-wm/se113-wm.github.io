### Duplicate Check Logic

```csharp
// Check for duplicate excluding current group
bool isDuplicate = db.UserGroups
    .Any(g => g.GroupName == GroupName.Trim() &&
              g.GroupId != SelectedItem.GroupId);

if (isDuplicate)
{
    ShowMessage(MSG22, "Group name already exists");
    return;
}
```
