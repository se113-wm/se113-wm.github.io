### Dialog Flow

```csharp
if (!HasReferences(SelectedItem.GroupId))
{
    var result = MessageBox.Show(
        "Are you sure you want to delete this group?",
        "Confirm Delete",
        MessageBoxButton.YesNo);

    if (result == MessageBoxResult.Yes)
        DeleteGroup();
}
```
