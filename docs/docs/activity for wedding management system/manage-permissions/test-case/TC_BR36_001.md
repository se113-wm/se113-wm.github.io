### Delete Order

```csharp
// Delete order for referential integrity:
// 1. Delete from Permission table (child)
// 2. Delete from UserGroup table (parent)
db.Permissions.RemoveRange(
    db.Permissions.Where(p => p.GroupId == groupId));
db.UserGroups.Remove(group);
db.SaveChanges();
```

### Database Verification

```sql
-- Before delete:
SELECT * FROM Permission WHERE GroupId = 'TEST_GROUP'
-- Expected: Multiple records

-- After delete:
SELECT * FROM Permission WHERE GroupId = 'TEST_GROUP'
-- Expected: 0 records
```
