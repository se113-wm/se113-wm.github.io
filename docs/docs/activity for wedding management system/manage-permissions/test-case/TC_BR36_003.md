### Refresh Logic

```csharp
// After successful delete:
GroupList = new ObservableCollection<UserGroup>(
```

| Step | Steps to Perform                               | Step Expected Result                 |

| 4    | Click Delete and confirm "Yes"                 | Delete confirmed                     |
| 5    | Observe DataGrid refresh                       | DataGrid refreshed                   |
