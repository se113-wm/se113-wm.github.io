| 5    | Observe form fields                               | Form fields cleared/reset                          |
| 6    | Check IsEditing and IsPasswordChangeEnabled flags | IsEditing = FALSE, IsPasswordChangeEnabled = FALSE |

| Criteria      | Pass                              | Fail                |

| IsEditing     | ✓ Set to FALSE                    | ✗ Remains TRUE      |
