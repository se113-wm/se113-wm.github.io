### Transaction Logic

```csharp
using (var transaction = db.Database.BeginTransaction())
{
    try
    {
        // Update parameters
        db.SaveChanges();
        transaction.Commit();
    }
    catch (Exception ex)
    {
        transaction.Rollback();
        ShowError(MSG28);
    }
}
```
